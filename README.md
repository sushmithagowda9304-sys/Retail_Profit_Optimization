# Retail Profit Optimization

## Project Overview
This project analyzes a retail sales dataset to identify key drivers of sales and profitability using Python and data visualization.

## Business Objective
- Analyze sales and profit performance
- Identify high-performing and loss-making products
- Evaluate regional and customer segment performance
- Study the impact of discounts on profitability
- Provide actionable business recommendations

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Insights
- Technology generated the highest sales and profit.
- Copiers were the most profitable sub-category.
- Tables consistently generated losses.
- Consumer was the highest-value customer segment.
- Higher discounts negatively impacted profitability.
